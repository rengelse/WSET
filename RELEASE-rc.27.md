# WSET v1.4.4-rc.27 – Dynamic Property Publication

Based on rc.26. Nettsider → Eiendommer has a direct parent toggle and child rows for Nybygg and Bruktboliger. Each child is selectable for local preview and category-specific settings; the tree and inspector use the same persisted command and flags. Parent OFF disables child controls without erasing their selections. Selected category is retained in workspace context.

## Compatibility and publication
- Both categories default ON regardless of local XML inventory. Legacy implicit false (missing/false `visibilityExplicit`) migrates to true. A marked manual OFF is preserved. The existing parent page flag is preserved; older projects without the parent use their previous effective parent default. An unmarked manual OFF from outside the editor cannot be distinguished from the legacy default; check the switches before generating.
- WSET saves migrated values with the existing revision/backup mechanism before generating. Already imported rc.23 source projects do not require reimport; rc.27 also verifies the actual exported PHP configuration and per-language routes. Matching standalone website source is supplied separately for new imports/direct website builds.
- Server PHP already discovers XML at request time. It is unchanged, including deliberate visibility choices and validation. With the page and categories enabled, server-only XML does not need a local import. Category follows New/ or Existing/ folder. Valid published sale listings are read, not rental/non-public records. No private data is made public. Existing two-ZIP workflow remains unchanged. The local preview cannot see server-only data.
- For an update, extract the two generated ZIPs to their respective destinations, preserve existing server XML, images, private settings and other runtime data (do not overwrite newer private feed files), remove obsolete *public* paths per removal list, and verify PHP is serving the new files. Do not delete private folders. No automatic server upload or installation.
