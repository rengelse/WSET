# WSET v1.4.4-rc.23 — Universal Text Editing

## Scope
Based on rc.22. Coordinated with the supplied CBPM-WSET-PROSJEKT-rc.16 ZIP. The new `wset-editable-elements-v1` descriptor and explicit record/field metadata are included in the separate rc.23 website project. No replacement of user project data, website CSS, assets, PHP or Assistant code. The old project can still be opened; import the separate updated project as a new copy for testing. The original `project/website.json` in the supplied site ZIP is unchanged byte for byte.

## Changes
- `core/text-structure.mjs`, `core/universal-text.mjs`: one shared structural text-binding pass for preview and WSET publication. Exact binding markers distinguish normal and emphasized parts of headings, and repeated fixed strings. Neutral `site-text` inline wrappers preserve the template's existing CSS behavior. Older unique fixed text IDs remain compatible; duplicate/previously unaddressable fixed strings have section-local occurrence IDs. These are tied to the source structure and original text, so this is not a fully generic semantic-ID contract for arbitrary future HTML.
- `core/inline-editing.mjs`, `core/content-commands.mjs`, `core/editor-operations.mjs`: canonical model binding for services, projects, staff and reviews, including service list items and project place. Independent occurrence overrides are data-only and escaped; existing undo/redo and archive storage apply. Legacy fixed overrides are preserved.
- `core/design-styles.mjs`, `core/website-generator.mjs`, `core/preview-editor-map.mjs`, `core/preview-server.mjs`, `preview/bridge.js`: context selection, effective formatting and inline editing use the same structural binding. Public ZIP generation validates its text bindings against the trusted renderer, uses stable record selectors, updates checksums, removes preview binding markers and includes saved fixed-text occurrence edits. Private ZIP is unchanged.
- `engines/cbpm-astro-v1/lib/render-site.mjs`, separate website `src/lib/render-site.mjs`, `public/site.js`: explicit record/field IDs for static content and the review carousel. Descriptor: `editable-elements.json`. `core/project-archive.mjs` preserves/validates the versioned descriptor when exporting/importing projects.
- `ui/app.js`, `ui/index.html`, package metadata: support the new occurrence command in the full section panel; retain rc.22 UI and keyboard workflows.

## Boundaries
This release covers visible, mapped text in static main sections. Header/footer navigation, dynamic PHP property pages, modals and client-generated content are not universally editable inline. Some unbound/hidden/empty elements still use existing panels. Inline-run alignment is not free layout positioning. Older rc.16 source without new field metadata can be opened, but updating the actual source template is recommended, notably for carousel record style identity. Static fixed slot IDs are structural and need migration if the template markup/original translations change. No layout drag-and-drop feature added.
