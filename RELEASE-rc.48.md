# WSET v1.4.4-rc.48 – My Websites / Project Dashboard

Base: rc.47 Workspace & Automatic Library Synchronization. Existing workspace directories, renderer contracts, template ZIP discovery, editor, property and Smart Assistant modules, and two-ZIP publication workflow remain intact. No new commercial templates.

## My Websites
- The existing Mine nettsteder navigation opens a dedicated dashboard fed by the persistent workspace project registry, not recent history. Works before opening any website. The separate Overview startup is retained.
- Shows counts for all readable/discovered projects, active project, projects with an administrative domain and distinct templates in use. Domain is a user-supplied note, not proof of connection or publication. No invented completion percentages or publication status.
- Grid and list views; search by project name, website name, customer, domain, folder and template; filter by active project, presence/absence of domain or site read error; sort by saved time, name or creation date. Page size 12; view preference stored locally. Refresh manually to discover changes; the dashboard also reloads on entry. Template folder auto-sync from rc.47 is unchanged.
- Card: saved homepage cover (not a website screenshot), fallback initials, template and version, active/unsaved badge, customer, domain, saved timestamp and saved page/language/media counts. The imported-media count is not a count of all physical asset files. Preview images are local raster only, up to 2 MiB each. Images are fetched in bounded batches, cached within the current dashboard and never fetched from remote URLs. No imported code is executed.
- Details dialog edits project display name, customer and domain. These are optional administrative fields in `.wset-local-project.json` under the project root, preserving the existing project UUID. Name defaults to saved website brand/folder name. The metadata is excluded from editable website archives and project copies, just like the original local identity file; it does not alter the actual website or server profile. Deleting the registry and rescanning recovers project metadata from the folders. The display name remains independent of the website brand name.
- Open/resume, show folder in Explorer, copy project and export editable project ZIP. Copy/export of a different project opens that project first through the existing discard/save guard and uses the original save-as/export workflows. New website opens the existing template chooser. ZIP import, folder open and workspace configuration remain available. No new destructive actions.
- Project lifecycle, manual/automatic progress, archiving and central backup management remain deferred. Live/full-homepage template gallery remains rc.49. Existing project-local save backups are unchanged.
