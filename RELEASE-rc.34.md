# WSET v1.4.4-rc.34 – Property Listing Editor

## Scope
Continues rc.33. Eiendommer → Nye annonser retains the approved tree editor, the existing local register and XML sources. No XML is generated or published in rc.34. No changes to website engine, XML parser, published site or deployment scripts. Property status and badges remain for rc.36.

- Image import through a dedicated authenticated Electron IPC with multi-select, bounded sizes, Sharp decoding and aspect-preserving WebP optimization (max 1920 px, no upscaling). Photo order, primary photo (first photo), floorplan role and removal of a photo reference are supported. The input file on the PC is untouched; the local draft stores the optimized copy, not a second full-resolution original. Removed/unreferenced draft images remain on disk to support undo and project recovery.
- `project/property-draft-images/` is private staging, not the ordinary media library and not the published XML or property image folder. The ordered photo metadata is stored in `propertyDrafts.items[].data.photos`. Full project ZIP includes these files; template ZIP excludes them and the drafts. rc.35 must explicitly stage approved images into `Existing/images/<reference>/` and build the matching XML URLs. Do not publish the staging directory.
- Coordinate editor supports manual WGS84 values and optional MapLibre GL JS 5.15.0 / OpenFreeMap Liberty (https://openfreemap.org/quick_start/). The map is loaded only on request, using WSET's own dependency, not imported project code. Click or drag the marker to update coordinates; no geocoding or reverse geocoding. The default map area is Costa Blanca if no coordinates have been entered. The provider receives ordinary map tile requests; address and description fields are not sent. Manual inputs remain usable without internet. Reopen the map to center on manually changed coordinates.
- Multilingual editing shows the project's default language for reference when present. A separate, optional local announcement preview shows selected language, photos, price, location and supported facts. This is an illustrative draft preview, not a rendering of the actual published PHP page.
- Existing Kyero fields retained; no unsupported title, economic fields or status elements invented. Reference/date/new_build are to be generated/mapped during rc.35, not new XML fields here.
