# WSET Editor v1.4.4-rc.47 – Workspace & Automatic Library Synchronization

Base: rc.46 Dynamic Template Preview. No changes to website design, renderer contract, property modules or publication ZIP layout.

## Workflow
- Open Workspace (Arbeidsområde) from Overview, My Websites or the application settings gear. Default `Documents/WSET` with Templates, Projects, Modules, Backups, Exports and Archive. Each directory can be chosen separately. Changing the root resets individual selections; existing files are not moved or deleted. Choose the previous module location again if necessary.
- Templates is the authoritative ZIP directory. Drop ZIPs into it or its non-hidden subdirectories. The main process scans at startup and approximately every five seconds; an open template dialog refreshes at the same interval. Manual synchronization and opening the source in Explorer are available. Categories and versions come from validated metadata, not filenames. Identical copies are deduplicated; conflicting content with the same ID/version is blocked. Invalid ZIPs are shown as diagnostic warnings; unsupported renderers can be catalogued but not activated. Symlinks inside the source tree are not followed. No code runs on discovery. Trusted-source confirmation is required before creating a project from a template; publication may run project build scripts.
- Manual import copies original ZIP bytes without overwriting an existing file. The library no longer deletes source files via the editor: remove them in Explorer. New projects and ZIP imports are independent copies under Projects; folders retain the archive name with a unique suffix. Exports default to Exports, template exports to Templates. Save As defaults to Projects but may use another folder.
- My Websites reads a persistent, rebuildable registry (not only recent history). It discovers direct child projects in Projects and the old internal projects directory, plus previously registered/recent locations. Local identity metadata `.wset-local-project.json` is outside the export contract and excluded from Save As copying. Registry is stored in Electron userData. Registry refreshed at startup, entering My Websites, and manual refresh; project status and progress dashboard follow in later releases.
- First launch copies old installed template ZIPs once into Templates (originals preserved); legacy projects stay in place to preserve path-dependent server settings. Existing installed modules keep their old directory as an initial override. Backups and Archive are reserved directories in rc.47; existing project-local backup behavior is unchanged. Missing prior directories are retained in the registry but unavailable projects do not show as openable entries. To relocate existing project folders, make a verified backup and manage the files explicitly; no automatic move or server-profile migration is implemented.
